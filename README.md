# Ardunio-Pizo-Drums

Details
This is an Arduino drum set that I made using piezoelectric sensors as the drums, and it uses an Arduino Mega 2560 as the microcontroler this poject took two months to build by myself.


Components

- 1 x Arduino MEga 2560
- 5 x 35mm Piezoelectric discs 
- 1 x 220 Ω resistor
- 5 x 1MΩ reistor
- 7 x Male to Male jumper wires
- 10 x Male to Female jumper wires
- 3 x 5mm diffused red LEDs
- 2 x 5mm diffused blue LEDs
- 1 x USB 2.0 Type A to B cable
  (cable can be included sometimes with some kits)
